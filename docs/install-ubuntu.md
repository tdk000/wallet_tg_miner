# Установка на Ubuntu — по шагам, для новичков

Это офлайн-программа: подбирает «красивый» адрес кошелька Telegram Wallet
(например, чтобы он заканчивался на `TG`). Работает только на твоём компьютере,
в интернет не ходит.

Есть два способа. **Способ 1 проще** — ничего не надо компилировать.

---

## Способ 1. Готовый файл (рекомендуется)

Нужен только `curl`, он в Ubuntu есть по умолчанию. Никакого `sudo`, никакой сборки.

### Шаг 1. Открой Терминал

Нажми **Ctrl + Alt + T**.
Если не открылось: нажми клавишу **Windows** (Super), набери `Терминал`, запусти.

Появится тёмное окно с мигающим курсором — так и должно быть.

### Шаг 2. Скопируй одну строку, вставь, нажми Enter

```
mkdir -p ~/wallet-tg && cd ~/wallet-tg && curl -L -o wallet-tg https://github.com/tdk000/wallet_tg_miner/releases/latest/download/wallet_tg_miner_linux_x86_64 && chmod +x wallet-tg && ./wallet-tg --selftest && echo "alias wallet-tg='$HOME/wallet-tg/wallet-tg --wizard'" >> ~/.bashrc && echo "ГОТОВО"
```

**Вставить:** в Терминале это **Ctrl + Shift + V** (не Ctrl + V!), либо правая
кнопка мыши → «Вставить».

Скачается файл ~1,3 МБ и сразу прогонит самопроверку. Ждать несколько секунд.

### Шаг 3. Проверь результат

В конце должно быть:

```
[ok]   fallback check checksum error
all self-tests passed
ГОТОВО
```

`all self-tests passed` = скачалось правильно, криптография совпадает с эталоном.

### Шаг 4. Закрой Терминал и открой заново

Один раз, чтобы запомнилась короткая команда запуска. Снова **Ctrl + Alt + T**,
набери `wallet-tg` и Enter. Откроется меню на русском.

### Шаг 5. Как пользоваться меню

Отвечай цифрами, после каждого ответа — Enter:

1. Язык → `1` (Русский)
2. Что сделать → `1` (найти красивый адрес)
3. Желаемое окончание адреса → например `TG` или `ton` (буквы и цифры, 2–4 символа)
4. Режим → `1` (рабочий — **рекомендуется**: именно он даёт адрес, который
   потом появится в Telegram)

Дальше программа покажет прогресс, найдёт адрес и выведет его вместе с 12 словами.

### Если у тебя ARM (Raspberry Pi, ARM-сервер)

Проверить: в Терминале набери `uname -m`. Если ответ `aarch64` — в строке из
шага 2 замени `wallet_tg_miner_linux_x86_64` на `wallet_tg_miner_linux_aarch64`
(и `-o wallet-tg` можно оставить как есть).

## Способ 2. Из исходников

Если хочешь собрать сам или у тебя нестандартная система. Нужны `git` и компилятор —
строка поставит их сама (попросит пароль от аккаунта Ubuntu).

```
sudo apt update && sudo apt install -y g++ git && rm -rf ~/wallet_tg_miner && git clone -q https://github.com/tdk000/wallet_tg_miner ~/wallet_tg_miner && cd ~/wallet_tg_miner && sh build.sh && ./wallet_tg_miner --selftest && echo "alias wallet-tg='$HOME/wallet_tg_miner/wallet_tg_miner --wizard'" >> ~/.bashrc && echo "ГОТОВО"
```

**Про пароль:** при вводе пароля на экране **ничего не появляется** (даже звёздочек).
Это нормально: печатай вслепую и жми Enter.

**Сколько ждать:** 1–3 минуты (скачивается компилятор, ~100 МБ).

Дальше всё как в способе 1: шаг 3 (проверка), шаг 4 (перезапустить Терминал),
шаг 5 (меню).

---

## Сколько ждать результата

Чем длиннее окончание, тем дольше поиск. Для обычного домашнего компьютера (4 ядра):

| Окончание | Пример | Сколько ждать |
|---|---|---|
| 2 символа | `UQ......TG` | секунды |
| 3 символа | `UQ.....ton` | 5–15 минут |
| 4 символа | `UQ....wo1f` | 6–10 часов (можно оставить на ночь) |
| 5 символов | — | недели, лучше не начинать |

Во время поиска: окно Терминала можно **свернуть**, но не закрывать. Если
выключить компьютер — поиск начнётся заново. Остановить: **Ctrl + C**.

## Что делать с найденным

Программа выведет примерно такое:

```
=== FOUND ===
  address     : UQ....TG
  mnemonic    : word1 word2 word3 ... word12

  RESULT   : YES - import this phrase into Telegram Wallet
```

1. **Сохрани 12 слов** (это доступ к деньгам — на бумагу, не в переписку).
2. Telegram Wallet (@wallet) → «Импортировать кошелёк» → введи эти 12 слов.
3. **Сверь адрес** в кошельке с найденным — символ в символ.
4. Только после этого пополняй.

Если написано `RESULT : NO` — был выбран «быстрый» режим (пункт 2 вместо 1).
Такой адрес в Telegram не появится. Запусти `wallet-tg` снова и выбери режим **1**.

## Если что-то пошло не так

**`wallet-tg: команда не найдена`**
Закрой Терминал и открой заново (шаг 4). Если не помогло — запусти полностью:
`~/wallet-tg/wallet-tg --wizard` (для способа 2: `~/wallet_tg_miner/wallet_tg_miner --wizard`).

**`curl: command not found`**
Поставь curl: `sudo apt install -y curl`, потом повтори строку из шага 2.

**`Неверный пароль` / просит пароль повторно**
Это пароль от аккаунта Ubuntu, не от Telegram. При вводе не отображается — печатай
вслепую и жми Enter.

**`Unable to locate package g++`**
Нет интернета или устарели списки пакетов. Проверь сеть, повтори строку целиком.

**`Permission denied`**
Строка из способа 1 уже делает `chmod +x`; если запускаешь файл вручную, выполни
`chmod +x wallet-tg` в его папке.

**Хочу обновить до свежей версии**
Способ 1: повтори строку из шага 2 (файл перезапишется свежим).
Способ 2: повтори строку из способа 2.

**Хочу удалить**
Способ 1: `rm -rf ~/wallet-tg && sed -i '/wallet-tg=/d' ~/.bashrc`
Способ 2: `rm -rf ~/wallet_tg_miner && sed -i '/wallet-tg=/d' ~/.bashrc`

## Важно (коротко)

- 12 слов — это доступ к деньгам. **Никому** их не показывай и никуда не вставляй,
  кроме импорта в самом Telegram Wallet. Ни один «сервис проверки» их спрашивать не должен.
- Адрес, который покажет Telegram после импорта, **обязательно сверь** с найденным,
  и только потом переводи деньги.
- Программа не делает сетевых запросов: можешь отключить интернет после установки —
  поиск всё равно работает.
- Готовые статические сборки не используют GPU. Для `--gpu` собери динамически
  (см. README, раздел 2).
