# Установка на Windows — по шагам, для новичков

Это офлайн-программа: подбирает «красивый» адрес кошелька Telegram Wallet
(например, чтобы он заканчивался на `TG`). Ничего не устанавливает в систему,
в интернет не ходит.

## Что качать

На странице [Releases](../../releases/latest) лежит несколько файлов. Тебе нужен
**один** — с «windows» в названии:

| Файл | Для чего |
|---|---|
| **`wallet-tg-windows-x86_64.zip`** | **Windows — это он** |
| `wallet-tg-linux-x86_64.tar.gz` | Linux (обычный ПК/сервер) |
| `wallet-tg-linux-aarch64.tar.gz` | Linux на ARM (Raspberry Pi) |
| `app-debug.apk` | Android-телефон |

Прямая ссылка на нужный файл:
<https://github.com/tdk000/wallet_tg_miner/releases/latest/download/wallet-tg-windows-x86_64.zip>

---

## Шаг 1. Скачай архив

Нажми ссылку выше (или открой Releases и выбери файл с «windows») — начнётся
загрузка `wallet-tg-windows-x86_64.zip`, около 180 КБ.

## Шаг 2. Распакуй

Открой «Загрузки», нажми на архив **правой** кнопкой → «Извлечь всё…» →
«Извлечь». Получится папка, в ней два файла:

```
wallet_tg_miner.exe
start.bat
```

Можно перетащить папку куда удобно, например на Рабочий стол.

## Шаг 3. Запусти

**Двойной клик по `wallet_tg_miner.exe`** — откроется мастер с меню на русском.
(Либо `start.bat` — простое меню, но в нём нет выбора языка.)

> **Windows может сказать «Windows защитила ваш компьютер»**
> Так бывает с любой программой без платной цифровой подписи. Нажми
> **«Подробнее»** → **«Выполнить в любом случае»**. Программа не ставится в
> систему, не просит прав администратора и не обращается к сети.

## Шаг 4. Ответь на вопросы мастера

Отвечай цифрами, после каждого ответа — Enter:

1. Язык → `1` (Русский)
2. Что сделать → `1` (найти красивый адрес)
3. Желаемое окончание адреса → например `TG` или `ton` (буквы и цифры, 2–4 символа)
4. Режим → `1` (рабочий — **рекомендуется**: именно он даёт адрес, который
   потом появится в Telegram)

Дальше пойдёт прогресс, а в конце — адрес и 12 слов.

---

## Сколько ждать

| Окончание | Пример | Сколько ждать |
|---|---|---|
| 2 символа | `UQ......TG` | секунды |
| 3 символа | `UQ.....ton` | 5–15 минут |
| 4 символа | `UQ....wo1f` | 6–10 часов (можно оставить на ночь) |
| 5 символов | — | недели, лучше не начинать |

Во время поиска окно можно **свернуть**, но не закрывать. Остановить: **Ctrl + C**.
Если выключить компьютер — поиск начнётся заново.

## Что делать с найденным

```
=== FOUND ===
  address     : UQ....TG
  mnemonic    : word1 word2 word3 ... word12

  RESULT   : YES - import this phrase into Telegram Wallet
```

1. **Сохрани 12 слов** — это доступ к деньгам (на бумагу, не в переписку).
2. Telegram Wallet (@wallet) → «Импортировать кошелёк» → введи эти 12 слов.
3. **Сверь адрес** в кошельке с найденным — символ в символ.
4. Только после этого пополняй.

Если написано `RESULT : NO` — был выбран «быстрый» режим (пункт 2 вместо 1).
Такой адрес в Telegram не появится: запусти заново и выбери режим **1**.

## Если что-то пошло не так

**«Windows защитила ваш компьютер» / «Приложение заблокировано»**
«Подробнее» → «Выполнить в любом случае». Антивирус может ругаться на
неподписанный exe — добавь папку в исключения, если доверяешь источнику
(файл собран из исходников этого репозитория автоматически, в GitHub Actions).

**В архиве нет `wallet_tg_miner.exe`**
Значит скачался не тот файл. Нужен именно `wallet-tg-windows-x86_64.zip`
(не `.tar.gz` и не `.apk`).

**Окно закрылось сразу после запуска**
Запускай `wallet_tg_miner.exe` двойным кликом из папки, а не из окна архива
(в окне архива файл может не распаковаться). Или запусти `start.bat`.

**Долго ничего не происходит**
Так и должно быть: идёт перебор. Прогресс печатается в том же окне (попытки,
скорость, проценты). Для 4 символов это несколько часов.

**Хочу удалить**
Удали папку с программой. В систему ничего не устанавливалось, реестр не
трогается.

---

## Важно (коротко)

- 12 слов — это доступ к деньгам. **Никому** их не показывай и никуда не вставляй,
  кроме импорта в самом Telegram Wallet.
- Адрес, который покажет Telegram после импорта, **обязательно сверь** с найденным.
- Программа не делает сетевых запросов: после запуска интернет можно отключить.
- GPU на Windows не нужен: по умолчанию считается на процессоре (все ядра).
